# Prompts index

**Purpose.** Reusable task prompts that are worth keeping because they are used repeatedly and are easy to get subtly wrong. Open it when a developer reaches
for a prompt by name; a session nobody sent here does not need it.

**Not for.** Workflow guidance an agent should follow whenever a task matches, which belongs in [`skills/`](../skills/_index.md). A prompt is something a human
reaches for deliberately; a skill is something an agent applies on recognising the situation.

**Conventions.**

- Add a prompt only after using it more than once. A prompt written speculatively is usually wrong.
- Keep a prompt self-contained: state its inputs, its expected output, and anything it must not do.
