# Research index

**Purpose.** Dated surveys of what exists outside this repository — tools, conventions, competing approaches — written to inform a decision that has not been
taken yet. A survey here is the input a design session reads instead of starting over. Open it when researching a question, or when a design needs the survey a
decision came from; an implementation does not.

**Not for.** Decisions themselves, which belong wherever this project records them, and descriptions of how the project currently works, which belong in
[`context/`](../context/_index.md). A research document that has been acted on stays as the record of why.

**Conventions.**

- One document per question, following [`../templates/research.template.md`](../templates/research.template.md).
- State the date researched and the status. Findings age, and a reader must be able to tell how much.
- Open with where the work stands, so a session resuming the question reads one line rather than the whole document.
- End with the sources, linked, each carrying its publisher and date. A claim nobody can check is an opinion.
- Mark a finding that has aged as historical rather than deleting it or restating it as current.
